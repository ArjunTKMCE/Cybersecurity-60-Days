\# Task 5: Capstone Project and Incident Response



\## Project

Web Application Penetration Testing Report



\## Objective

Identify common web application vulnerabilities, document findings, and recommend security mitigations using a controlled local lab.



\## Tools Used

\- Kali Linux

\- DVWA

\- Burp Suite

\- Nmap

\- curl



\## Activities

\- Reconnaissance and vulnerability testing

\- SQL Injection testing and mitigation

\- Stored, Reflected, and DOM-based XSS testing

\- CSRF and File Inclusion testing

\- HTTP request inspection using Burp Suite

\- HTTP security-header inspection

\- Documentation of findings and recommendations



\## Incident Response Methodology

1\. Identification

2\. Containment

3\. Eradication

4\. Recovery

5\. Lessons learned



\## Mitigation Recommendations

\- Use prepared SQL statements.

\- Apply output encoding to prevent XSS.

\- Implement CSRF tokens for state-changing requests.

\- Validate file paths and user input.

\- Configure appropriate HTTP security headers.

\- Monitor logs for suspicious activity.



\## Evidence

Practical screenshots are stored in the Evidence folder.



\## Report

The Report folder contains the final project report.



\## Scope

Testing is limited to authorized systems in a local lab.
